# Blockbuster Movies Analysis Project

## Course Information
- **Course Code:** 2323 CIS - Introduction to Data Science
- **Institution:** King Khalid University - College of Computer Science

## 1. Objective and Data Question
- **Research Question:** How do movie budget, runtime, and MPAA rating impact audience ratings and box office revenue in modern cinema?
- **Practical Objective:** Apply the pre-modeling data science workflow (loading, cleaning, transformation, aggregation, and visualization) on a custom movies dataset.

## 2. Dataset Sources
- The dataset contains attributes such as movie title, release year, budget, revenue, runtime, and ratings.

## 3. Repository Structure
- `notebooks/analysis.ipynb`: The primary Jupyter Notebook containing all Python code.
- `data/`: Contains data files and source documentation.
- `outputs/figures/`: Stores exported visualizations.

## 4. Team Contribution Statement
- **Team Member 1:** Data Understanding and Loading.
- **Team Member 2:** Data Preparation, Cleaning, and Transformations.
- **Team Member 3:** Aggregation, Visualizations, and GitHub Publishing.
